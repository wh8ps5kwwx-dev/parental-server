About

Embedded monitoring with a child-friendly face

Built as a graduation project: dual mobile experience, Flask API, and Render hosting.

MYRana is a stealth-oriented parental control framework. On the child device, the visible experience is أكاديمية العباقرة (Academy of Geniuses) — an educational game interface. In the background, Usage Access and Accessibility enforce policies set by the guardian.

On the parent side, حماية الأطفال provides linking, app blocking, screen-time policy, alerts, reports, and messages. Parent and child apps talk to a shared Python Flask server deployed on Render (parental-server-4mms.onrender.com).

The stack includes the original Kotlin Android project (MYRana) and a Flutter/Dart port (myrana_flutter with native Kotlin enforcement on Android. iOS UI is limited (no native blocking).

Features

What the system actually does

Capabilities verified in the MYRana / Flutter codebase and graduation documentation — not marketing fiction.

Parent–Child linking (OTP + CHILD code)

Guardian verifies Gmail with OTP, pastes CHILD-XXXXXXXX, completes a 6-digit link code, and names the child device.

App block & freeze

Parent sends block/freeze/allow commands by package or app name. Enforcement uses foreground detection and Accessibility on Android.

Screen time & sleep schedule

Daily limits and sleep windows via screen-time policy APIs. Usage is collected with Usage Access and synced to the server.

Content / site filtering

Accessibility service matches blocked domains and risky keywords in monitored browsers and apps, then warns and alerts the guardian.

Background monitoring

Foreground service, WorkManager loops, and heartbeat keep policies active even when the academy UI is closed.

Alerts, reports & messages

Usage and content alerts on the parent dashboard, activity reports, and guardian messages to linked child devices — including multi-child accounts.

Objectives

Research & product goals

Aligned with the Stealthy Cyber Parenting Framework aims documented in the thesis materials.

  1. 1
    Design a child-friendly game interface

    Embed monitoring inside أكاديمية العباقرة to reduce the psychological pressure of overt surveillance tools.

  2. 2
    Deliver secure parental control

    Enable guardians to track app usage, manage screen time, and control content from حماية الأطفال.

  3. 3
    Keep protection durable

    Background services, permission checks, and authenticated linking reduce easy circumvention of policies.

  4. 4
    Support oversight with reports and alerts

    Provide structured usage visibility and event-driven alerts without requiring constant live watching.

Benefits

Who gains what

  • P
    For parents / guardians

    One account can link multiple children; set blocks and screen-time policy; receive content and usage alerts; send messages.

  • C
    For children (ages ~5–13)

    Primary UI is an educational academy game — not a “parental control” dashboard — while safety policies still apply.

  • F
    For families

    Balances digital safety with trust: technical controls without GPS stalking or inventing capabilities the apps do not have.

  • T
    For technical demonstration

    End-to-end graduation stack: Android (Kotlin/Flutter), Flask REST, SQLite, Render, Gmail OTP — reproducible on two phones.

Core value

Protection that stays present — without feeling like a cage

MYRana’s core idea is stealthy cybersecurity parenting: strong enforcement on Android (Usage Access + Accessibility + policies), secure OTP / CHILD-code linking, and a disguised child experience — so digital safety and psychological comfort can coexist.
